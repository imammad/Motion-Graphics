# Motion-Graphics

Remotion project (see README.md). Converting scenes to After Effects: use the `ae-builder` skill
(`.claude/skills/ae-builder/`) and follow its section 14, which records how this repo does it fast and the
After Effects errors already fixed. The finished pilot is `ae/FieldMarketing_ae/` (EventsScene); use it as the template.
The user wants these jobs done quickly, without setup questions the source code already answers.

Forex / gold / trading talking-head reels: use the `forex-trading` skill (`.claude/skills/forex-trading/`);
the finished example is `src/Anfaal/` (composition `AnfaalFOMC`, cover `AnfaalCover`).

Premium motion version of that style (approved later: glide motion, normal captions, chart cards, storyboard-first):
use the `forex-premium-motion` skill; finished example `src/GoldMoves/` (composition `GoldMoves2`, cover `GoldMovesCover`).
