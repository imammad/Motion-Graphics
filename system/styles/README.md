# Client styles

One filled-in copy of `system/docs/03-client-style-brief.md` per client, named `<client-name>.md`, next to its profile in `src/ReelKit/styles/<client-name>.ts`. Prompt 01 creates both.

`blue-minimal` (the reference reel look) is the default profile: `BLUE_MINIMAL` in `src/ReelKit/style.ts`.
