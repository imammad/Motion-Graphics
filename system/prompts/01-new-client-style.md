# 01 · New client / new style analysis

Use when: you get a new client or want a new editing style. Attach their reference reel(s) and any brand assets (logo, fonts, colours). Run once per client.

```
New client: [CLIENT NAME], niche: [NICHE]. Use the viral-talking-head-editor skill.

I've attached [N] reference reels they like and their brand assets. Analyse the references in detail, the way you analysed the original reference reel:
1. Pull frames twice a second and make timestamped contact sheets.
2. Write a shot list (time, line, scene type, what happens on screen).
3. Sample the exact colours (background, caption white, accent) and identify the fonts (suggest the closest free fonts if they are paid).
4. Measure caption size and placement, and describe the motion: how words enter, easing, durations, transitions, camera moves.
5. Map each animation to the four categories and the four scene types.

Then fill in system/docs/03-client-style-brief.md for this client and save it as system/styles/[client-name].md. Create the Style Profile src/ReelKit/styles/[client-name].ts (copy _template.ts) and render one test still for each scene type (captions, captions + UI, half screen, full screen) with the new profile so I can approve the look. Point out anything in their references that breaks our house rules and ask me whether to follow the client or the rules.
```
